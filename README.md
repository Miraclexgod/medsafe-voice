# MedSafe Voice: как запустить

Это сайт и маленькая серверная функция. Сайт показывает интерфейс, а функция `api/analyze.js` отправляет данные в Google Gemini и возвращает разобранный ответ. Ключ от Gemini хранится на сервере, в браузер он не попадает.

## Файлы

- `index.html`: разметка, все вкладки
- `style.css`: оформление
- `app.js`: логика кнопок, голос, медкарта, напоминания
- `api/analyze.js`: сервер — обезличивание, промпт и запрос к Gemini
- `knowledge.json`: база знаний (нормы анализов, чек-лист, правила безопасности, красные флаги)
- `ОБЪЯСНЕНИЕ.md`: как всё работает и ответы для шаблона КТ 3

## Запуск (минут 10)

1. **Ключ Gemini.** Зайдите на https://aistudio.google.com, нажмите «Get API key», потом «Create API key» и скопируйте ключ. Это бесплатно.
2. **GitHub.** Создайте новый репозиторий (например, `medsafe-voice`), нажмите «uploading an existing file» и перетащите туда ВСЕ файлы вместе с папкой `api`. Нажмите Commit.
3. **Vercel.** Зайдите на https://vercel.com через GitHub и выберите «Add New → Project». Найдите свой репозиторий и нажмите Import.
4. Перед Deploy откройте **Environment Variables** и добавьте переменную `GEMINI_API_KEY`, значение — ваш ключ. Нажмите **Deploy**.
5. Получите ссылку вида `https://medsafe-voice.vercel.app`. Справа вверху должно быть зелёное «ИИ подключён · Gemini».

Проверьте ссылку с чужого телефона, она должна открыться без входа. Логин и пароль не нужны.

## Если что-то не так

- **Жёлтый «Демо-режим».** Ключ не добавлен. В Vercel откройте Settings → Environment Variables, добавьте ключ, затем Deployments → Redeploy.
- **Ошибка про модель.** Добавьте переменную `GEMINI_MODEL` с названием модели из AI Studio (например, flash-модель из списка) и сделайте Redeploy.
- **Голос не работает.** Откройте сайт в Chrome или Edge и разрешите доступ к микрофону. В Safari и Firefox голосовой ввод может не работать, тогда вводите текст руками.
- **Не открывается анализ.** Файл должен быть до 3 МБ, фото или PDF.

Без ключа сайт тоже работает в демо-режиме со встроенными примерами ответов.
